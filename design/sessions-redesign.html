무엇이 바뀌었나

  • 두 칸 구조 — 왼쪽은 컴퓨터 목록(레일과 같은 말투), 오른쪽은 고른 컴퓨터의 세션. 다섯 대를 한 화면에 쌓던 긴 스크롤이 없어집니다.
  • “앱에 표시 중” / “앱에 없음”으로 나눔 — 연결 안 된 세션(weu, wox)은 카드 대신 한 줄로, 버튼도 흰색 대신 보통 버튼.
  • 보라 배지 정리 — 사이드바: ys-mac-kc-marketing 알약을 작은 mono 글씨(⧉ ys-mac-kc-marketing)로. 보라색은 “지금 보는 space”와 액션에만 씁니다.
  • 점 의미 분리 — 세션 실행 중은 초록, space 안의 에이전트 상태(작업 중 노랑·끝남 보라·막힘 빨강)는 기존 색 그대로라 헷갈리지 않습니다.
  • space가 많으면 접기 — 2줄(약 12개)까지 보이고 나머지는 +N개. + space는 칩 줄 끝 점선 칩으로 옮겨 버튼 수를 줄였습니다.
  • 연결 해제는 hover 때만 — 늘 보이던 해제 버튼을 카드에 마우스를 올릴 때만 보이게 하고, 두 번 눌러 확인하는 흐름은 그대로.
  • 검색 — /로 모든 컴퓨터의 space·세션을 찾아 Enter로 이동.
  • default (기본) → default + 작은 기본 태그.
